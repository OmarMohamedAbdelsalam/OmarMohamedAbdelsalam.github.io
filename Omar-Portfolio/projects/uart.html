UART TX & RX

Configurable UART transmitter and receiver implemented in Verilog, with parity support, prescale-based reception, error checking, self-checking verification and FPGA testing.

01 / OVERVIEW

Project overview

This project implements both sides of a UART communication link at RTL level. The transmitter serializes parallel data into a UART frame, while the receiver reconstructs the frame using configurable oversampling/prescale timing.

The design includes optional parity generation and checking, start/data/parity/stop handling, busy and data-valid control, and error detection.

02 / ARCHITECTURE

TX and RX design

UART TX uses FSM-based control, a serializer and parity generation to produce the serial frame through the TX output.

UART RX uses edge/start detection, a configurable prescaler, bit sampling, serial-to-parallel conversion, parity checking and stop-bit validation.

03 / VERIFICATION

Verification

The UART blocks were verified through simulation using testbench-driven scenarios covering normal transmission, parity configurations, different receiver prescale values and error conditions.

QuestaSim was used for waveform inspection and functional verification, while SpyGlass was used as part of the RTL quality-check flow.

04 / FPGA

FPGA implementation

The design was integrated for FPGA testing on an Artix-7 platform. A clock-generation stage was used to derive the required UART timing, and TX/RX loopback testing was used to validate the serial communication path on hardware.

The repository contains the RTL and supporting project material for reproducing the implementation.
